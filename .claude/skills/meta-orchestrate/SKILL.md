# Meta-orchestrate a register

Stay out of the code. Your context is the schedule, not the diff. Read the register once, map each item's file territory, and pair items that share nothing. Run two agents at a time, opus, `isolation: worktree`. Briefs are hands-off: execute however you wish, don't defer work, re-measure the register's counts, merge yourself with a merge commit, never a draft, no deploy, leave residuals as an issue comment. Inject the writing rules too: every agent reads the unslop skill and applies it to commit messages, PR bodies, and issue comments, prose only, verbatim operator quotes reproduced exactly. Relay only what you verified yourself; label a sibling's report as their claim. Between merges, pull main forward, sweep clean worktrees, and hand gate flakes to the next brief as ride-alongs. Resume killed agents; adopt orphaned branches. Sweep residuals by triaging solo, then batching disjointly. Ask operator questions, never answer them. Deploy once, verify live, write memory, close.
