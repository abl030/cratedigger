# Meta-orchestrate a register

Stay out of the code. Your context is the schedule, not the diff. Read the register once, map each item's file territory, and pair items that share nothing. Run three agents at a time, opus, `isolation: worktree`. Briefs are hands-off: execute however you wish, don't defer work, re-measure the register's counts, merge yourself with a merge commit, never a draft, no deploy, leave residuals as a new issue comment. Paste orchestrate-issue's "Running agents" rules into every brief verbatim, and the writing rules too: every agent reads the unslop skill and applies it to commit messages, PR bodies, and issue comments, prose only, verbatim operator quotes reproduced exactly. Relay only what you verified yourself; label a sibling's report as their claim. Between merges, pull main forward, sweep clean worktrees, and hand gate flakes to the next brief as ride-alongs. Resume killed agents; adopt orphaned branches. Sweep residuals by triaging solo, then batching disjointly, in rounds as the comments accrue rather than once at the end. Ask operator questions, never answer them. Merged main ships on the nightly rolling update, so there is no deploy step: deploy only when the register holds a user-facing change the operator wants live today. Write memory, close.
